# 🚀 Asteroid Survival Game (Pygame)

A simple arcade-style asteroid survival game built with **Python** and **Pygame**.

## 🎮 Gameplay
- Control a rocket using **WASD / Arrow keys**
- Shoot asteroids with **SPACE**
- Destroy asteroids to earn points
- Avoid collisions — one hit and it’s game over
- Press **R** to restart after game over

## 🛠️ Technologies
- Python 3
- Pygame

## ▶️ How to Run
1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r pygame
3. python main.py
