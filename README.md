# Python Games

A collection of three simple games written in Python.

## Games

| Folder | Game |
|--------|------|
| asteroid | Asteroid |
| pong | Pong |
| snake | Snake |

Each folder has its own README with details and instructions on how to play.

## Requirements

- Python 3

Install any extra libraries listed in each game's README.

## Run

Go into a game's folder and run its main file, for example:

    cd snake
    python main.py
